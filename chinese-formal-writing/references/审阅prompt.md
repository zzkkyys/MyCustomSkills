# 审阅工作流与 prompt

## 先定两个开关

用 prompt 之前先定清楚，否则返工：

**开关一：结构能不能动。** 见 `SKILL.md`。若用户说"按某某模板写的，别改框架"，就在 prompt 的【必须遵守的约束】里加一条：*骨架、编号体例、加粗位置、段落切分一律照旧，只改措辞；不得把 `**（1）…（2）…**` 改成连续段落，不得合并或拆分段落。*

**开关二：只给建议，还是直接给改稿。** 文稿要由作者本人过手时（署名材料多半如此），把【审阅任务】第 2 条和输出格式里的「修改后」删掉，并加一条：*只诊断并给出可直接抄用的改写句，不要产出整段替换文本。* 这比给整段更有用——作者能看清改了什么、为什么改。

## 两种审阅方式

1. **分批审阅**（大改一轮后整体过一遍）：把各章分批（例如每 2 章一批）分别审阅、各自返回问题清单，再汇总修订。若当前环境支持并行子代理或多会话，可用它们做第二视角；若没有，就在同一会话里按批逐次审。注意：转发型子代理有时只提交异步 task 不返回内容，需显式要求它把审阅结论正文返回。
2. **逐段精修**（定稿前）：把正文一段一段发给外部 AI，用下面的可复用 prompt 模板。适合精雕开头句、口语残留、用词一致性。

## 逐段审阅 prompt 模板

下面模板以**课题申报书**为例，其它中文学术/公文文体（论文、研究报告、方案等）套用时，把「文档背景」和角色设定换成对应文体即可，文风标准通用。用前先把 `〔…〕` 占位符替换成本文稿的信息（主题、主线、固定术语等）。术语一致、保留结构标记、提防膨胀等约束已内置为规则。若只想让它挑问题、自己动笔改，删掉「审阅任务」第 2 条和输出格式里的「修改后」。

```
你是一位负责科研课题申报书润色的中文学术编辑。我会逐段发给你一份申报书的正文，请你对每一段做审阅和润色。

【文档背景】
这是一份〔课题层级，如省部级/国家级〕课题申报书，主题为《〔课题标题〕》，研究〔一句话说明研究对象与目标〕。全篇的主线是〔主线内容〕，〔次要方面〕只是配套/底座、占次要篇幅。全文已完成一轮学术化重写，我现在逐段做精修。

【必须保持的文风标准】
1. 学术书面语，不用口语。段落首句原则上为概括本段核心的"主题句"，不得用"这项研究要回答的是…""如果说…就是…""随着…""在…背景下…"这类口语承接或背景铺垫开头；确需先交代背景时，也应在段内尽快给出明确论点。
2. 除申报模板明确要求、以及关键问题/创新点/进度阶段/成果清单等需要评审逐条数点的部分外，不把正文写成列表、编号小标题或表格，一律用连续段落表达。
3. 不堆砌英文缩写和技术术语，必要概念用中文表述。
4. 尽量不用双引号和破折号；不用口号式三字/四字并列（如"更快、更好""可评可管可推广"），"A、B与C"三字并列改为双字名词词组或展开为完整陈述。
5. 删除口语衔接词与插入语："需要说明的是""需要特别指出的是""值得强调的是""总体而言""在此基础上""与此同时""也就是说""换句话说"——能删就删，靠内容逻辑衔接。注意不是删除所有连接词：表达因果、递进、分述关系所必需的句内连接（如"进而""据此""相应地"）可保留，只是不得用作段首空泛套话。
6. 去工作汇报腔（"陆续上线""稳步推进""扎实落地""初步显现""可操作、可落地"）与模糊副词（"稳妥""妥善""稳健"），改中性、具体的学术判断。
7. 克制形容词与程度副词：不用"显著""较大""高度""实质性推进""核心突破"等无客观依据的程度标记；差异用"相比既有研究，本课题的差异在于……"客观陈述，不做自评式夸大，不用"首创""国际领先""颠覆性"。
8. 拆长句：定语超过三个、或主谓间插入超过二十字，拆成两句或把定语后置。
9. 重心不能改：〔主线内容〕是主线，〔次要方面〕是配套、只是其中一部分，不得让配套内容喧宾夺主。
10. 避免用"课题/研究"作拟人主语去接"梳理、搭建、建立"等动作；宜用无主语承接或"课题组"等恰当主语。
11. 标题（研究内容/章节/创新点）用规范学术名词短语，不用口号式动词并列（如"……赋能……、提升……的方法"）、不用管理黑话（赋能、抓手、闭环、底座等）；同级标题句式与粒度保持一致。

【必须遵守的约束】
1. 术语保持全文统一，不得改动下列固定提法：〔逐一列出本课题的固定术语，如"术语A（而非某变体）""术语B"…〕。
2. 关键问题与创新点中的"第一/第二…"序数、进度安排中的"第一阶段…"等结构标记是有意保留的（便于评审数点、看时间轴），不要去掉。
3. 润色后字数与原段相当，不得明显膨胀；不得把删掉的列表、表格、英文术语重新加回。
4. 不得新增任何事实性内容（数字、机构、方法、结论等）。确实需要补一个数字或版本号才能把话说完整时，照写并在段末用【待核】标出，例如"【待核：样本规模需作者确认】"——申报书里的数字是对评审的承诺，不能由润色环节替作者拍板。
5. 同时检查语义与逻辑，不只看文风：定义是否循环（被定义项出现在定义里）、指示代词有无先行词、主语是否中途丢失、句子主干是否完整、本段陈述是否与前文某处矛盾。这类问题比口语味严重。

【审阅任务】
对我给出的这一段，请：
1. 指出其中偏口语、偏工作汇报腔、语义不严谨、动宾/词语搭配不当（如"回应……不足"）、名词堆叠过密、长句负荷过重或前后用词不一致的具体问题；
2. 给出润色后的完整段落（学术、通顺、书面）；
3. 若该段无明显问题，直接说明"可保留"并简述理由。

【输出格式】
- 问题：（逐条列出，定位到具体词句）
- 修改后：（给出完整段落）
- 说明：（一句话总结改动要点）

下面是需要审阅的段落：
【在此粘贴一段正文】
```

## 填写要点

- 【文档背景】和【必须遵守的约束】第 1 条是每个课题特有的，务必替换。主线/次要方面在标准第 9 条也要同步填。
- **逐段审阅有个固有盲区**：术语漂移、跨节复读、引文顺序都是跨段落的，一段一段看永远看不见。这三类必须先用 `scripts/audit.py` 全局跑一遍，再进逐段流程。
- 固定术语从 `学术化过稿清单.md` 里前置整理的术语表直接搬过来，保证审阅口径与写作口径一致。

## 一个最小示例（与具体学科无关，示意输入输出形态）

**输入段落：**
> 需要说明的是，随着相关技术的不断发展，本研究要回答的是如何显著提升评价的准确性。在此基础上，我们将稳妥地构建一套可评可管可推广的指标体系，扎实推进相关工作。

**期望输出：**
- 问题：①"需要说明的是""随着…""在此基础上"为口语衔接与背景铺垫开头，首句非主题句；②"本研究要回答的是"以研究作拟人主语并口语化；③"显著提升"程度副词无依据；④"稳妥地""扎实推进"为模糊副词与汇报腔；⑤"可评可管可推广"为口号式三字并列。
- 修改后：评价指标体系的构建，旨在提升评价的准确性与可比性。该体系依据…（明确维度）筛选核心指标并确定权重方法，形成口径统一、便于核查的完整框架。
- 说明：删口语开头与拟人主语，去程度副词与口号并列，首句改为概括本段的主题句。
