# 列表/表格 → 主题句段落 的改写

申报书正文应是连续论述，不是清单。评审读到满屏 `(1)(2)(3)` 和加粗小标题，第一反应就是"AI 生成/未打磨"。

## 需要改写的四种形态

1. **"目标:/主要内容:(1)(2)(3)"式条目**（研究内容、研究意义最常见）。
2. **加粗编号小标题**：`**（一）……** **（二）……**` 或 `**1. ……**` 后接一句话。
3. **表格**：把行列关系用文字表达。
4. **短句罗列**：一行一个要点、无连接词的堆叠。

## 改写手法

### 手法一：主题句领起 + 过渡句衔接

把"目标 + 若干要点"合成一段：首句用一个主题句概括这项内容要解决什么，随后把各要点用体现内在逻辑的衔接词串成连贯论述，如表并列的"其一……其二……"、表递进的"进而""据此"、表分述的"在……方面""难点在于……"。

**注意与去口语化规则的区别**：这里说的是**句内**用来表达要点之间逻辑关系的衔接，是必要的；`去AI味核对清单.md` 禁止的是**段首**那种不承载逻辑的套话式插入语（"需要说明的是""总体而言""在此基础上，"作独立起头）。同一个词放句中承接逻辑可以，放段首当万能过渡就删。优先用能表达确切关系的词（进而/据此/相应地），少用可有可无的填充词。

**改写前（示例，与具体学科无关）：**
```
研究内容二：评价指标体系构建
目标：建立科学的评价指标体系。
主要内容：
(1) 梳理相关维度；
(2) 筛选核心指标；
(3) 确定权重方法。
```
**改写后：**
> 评价指标体系的构建，旨在为研究对象提供可量化、可比较的衡量依据。为此需要先梳理若干评价维度并界定各维度的内涵；据此从中筛选出兼具代表性与可获取性的核心指标，剔除相互冗余的项；进而确定各指标的权重方法，形成层次清晰、口径统一的完整指标体系。

### 手法二：表格转叙述

表格若是"维度 × 取值"，改写为"在 A 方面……在 B 方面……"的分述段落；若是"对照/比较"，改写为"相比 X，Y 的优势在于……"。只有当信息本身是密集查表型（如术语表、指标定义表、变量—方法对照表）且放正文确实更清晰时，才保留为表——而且优先下沉到附录。

### 手法三：编号小标题降级为段内序数

评审习惯在"关键问题""创新点""进度阶段"处数点，这些地方的"第一/第二…""第一阶段…"是**有意保留**的结构标记，不要清掉。但要把它们从**加粗独立小标题**降级为**段落内的序数词**，让每一点自成一个有主题句的段落，而不是一个光秃秃的标题加一句话。

## 保留 vs 化解 的判断

- **保留为显式序数**：关键问题、创新点、进度阶段、预期成果条目——评审要数数量、看逐条。用"第一，……。第二，……。"的分段陈述，每段是完整论述。
- **化解为叙述**：研究目标、研究意义、研究方法、组织形式、价值分析——这些本是连续论证，不该切成条目。
- **改写后自检**：每段开头是不是主题句？段与段之间有没有逻辑过渡？有没有一整段其实只有一句话（说明还没展开、仍是伪列表）？
