# 学术化过稿清单（终稿前逐遍执行）

初稿完成后不要一次通读求全，容易顾此失彼。按下面的**分遍专项检查**过稿，每遍只查一类问题。若时间允许，终稿后放置一段时间（"冷却期"，理想 24 小时）再查，更容易发现自己的口语惯性。症状与对治的完整解释见 `去AI味核对清单.md` 与 `可读性核对清单.md`。

## 顺序：先机械、后判断

遍次的排列**不是按问题类型，而是按"能不能机械发现"**。第 0 遍全部可脚本化、修复是全局替换；后面各遍需要逐段判断。

**先做第 0 遍，再逐段精修。** 顺序颠倒会返工：若先逐节精修完前几章，再发现全书术语不统一，统一口径时会把已定稿的措辞连带推翻，等于同样的活干两遍。实测吃过这个亏。

| 遍次 | 查什么 | 方式 |
|---|---|---|
| 0 | 术语漂移、跨节复读、引文顺序、图表引用、体例计数 | `scripts/audit.py`，一条命令 |
| 1 | 可读性与逻辑（循环定义、指代悬空、自相矛盾…） | 逐段，见 `可读性核对清单.md` |
| 2 | 分寸与证据（预设结论、绝对化、结论超出数据） | 逐段，见 `分寸与证据.md` |
| 3 | 主题句与拟人主语 | 逐段 |
| 4 | 长句拆解 | 逐段 |
| 5 | 口语衔接词与插入语 | 检索 + 逐处判断 |
| 6 | 三字并列、汇报腔句型与机械段尾 | 检索 + 逐处判断 |
| 7 | 形容词、程度副词、模糊副词、搭配 | 检索 + 逐处判断 |
| 8 | 回归：复查前几遍自己改出来的问题 | 见文末 |

## 第 0 遍：全局机械审计（先跑这个）

```bash
python3 scripts/audit.py 正文目录/ --skip 00-      # --skip 排除说明、台账一类非正文
```

一次报出六类：**术语漂移**（同一概念多种叫法）、**跨节复读**（同一判断在不同章节逐字复现）、**引文编号是否按首次出现顺序**、**孤图与重复图题**、**体例计数**（加粗编号小标题、破折号、引号）、**口语词与程度副词计数**。

三点使用要领：

- **术语漂移是最大的一类**。实测一份六节的申报书里，同一概念出现过五种叫法、跨五个文件十三处；判据界限有五种说法；"额外信息／增量信息"混用十二处。这一类往往占全部改动的一半以上，而且全部可机械发现——但它在写作时几乎不可能靠自觉避免，因为术语是边写边长出来的，等意识到该建表时漂移已经发生。
- **跨节复读要先分清两种情况**：固定术语串（如三个评价维度连写）重复是正常的；同一句**判断**在不同章节逐字复现，才是 AI 生成稿的签名，评审读到会认为在凑篇幅。留在证据最足的地方——需要文献支撑的留在综述节。
- **脚本只报机械项**。读不懂、逻辑矛盾这类要靠第 1 遍逐段看。

## 第 1 遍：可读性与逻辑

逐段按 `可读性核对清单.md` 过一遍：循环定义、属概念错位、指代悬空、主语丢失、句子残缺、内部自相矛盾、正文与图表公式不一致。

这一遍**必须排在其它逐段遍次之前**：它查的是读者能不能读懂，比"像不像 AI"严重得多；而且后面几遍会大量删改句子，指代悬空和自相矛盾恰恰最容易被改稿本身制造出来（所以第 7 遍还要再回来查一次）。

## 第 2 遍：分寸与证据

逐段按 `分寸与证据.md` 过一遍，盯住三个词类：

- **动词**：形成、给出、揭示、阐明 → 检验、界定、比较、估计
- **情态**：必然、始终、完全、都会 → 可能、通常、相对、在……条件下
- **范围词**：均、全面、所有 → 逐项分述，把落后的那一项也写出来

这一遍必须排在文体各遍**之前**：改分寸往往要动整句的动词与情态，先润色会白做一遍。也必须排在可读性之后：句子还读不通时，判断不了它有没有说过头。

## 第 3 遍：主题句与拟人主语

- 逐段看首句是否为概括本段核心的主题句；若以"随着…""在…背景下…""这项研究要回答的是…"开头，调整为直接陈述。
- 检索以"研究/本课题"作主语接动作（"研究梳理…""课题回答…"）的句子，改无主语承接、被动式或"课题组"。

## 第 4 遍：长句拆解

规则：**定语超过三个，或主谓之间插入超过二十字，一律拆分。** 拆成两句，或把部分定语后置为补充说明。

例："兼具理论解释力、实践适用性和数据可获得性的分析框架" → "构建具有理论解释力的分析框架，并说明其适用条件与数据来源"。

## 第 5 遍：口语衔接词与插入语

检索下列高频口语词，逐一审视能否删除或替换（多数可直接删）：

```
需要说明 需要指出 需要特别指出 值得强调 值得注意
总体而言 综上所述 从…看 从政策导向看
在此基础上 与此同时 同时 此外 另外
也就是说 换句话说 简而言之 一言以蔽之
```

同时检索 `（` 和 `——`，把括号插入语融入正文或改脚注，把破折号改逗号/冒号或拆句。

## 第 6 遍：三字/四字并列、汇报腔句型与机械段尾

- 检索任何"A、B与C""A、B、C"的三字并列（如"可评可管可推广""更准更快更好"），一律改为双字名词词组或展开为完整陈述。
- 检索汇报腔句型："一是…二是…三是…""既要…又要…""不仅…而且…""正由…向…转变"，改为静态判断句式（体现为/包括/体现在）或有主题句的分段论述。
- 检索汇报腔动词："陆续上线""稳步推进""扎实落地""初步显现""可操作、可落地"，换成中性事实陈述。

## 第 7 遍：形容词与夸大

- 检索程度副词：`显著 较大 高度 实质性 核心突破 大幅 极大`。逐个问：有客观依据支撑吗？没有就删或改中性。
- 自评式表述（"核心突破""实质性推进""高度契合"）改客观描述："本课题提出……""该方法的特征在于……""相比既有研究，差异在于……"。
- 确认"颠覆性""国际领先""首创"等绝对化词汇为零。

## 第 7 遍（续）：模糊副词与搭配

- 检索模糊副词：`稳妥 妥善 稳健 稳步 切实 扎实`。审视有无精确指向，能删则删、能具体化则具体化。
- 检查动宾/词语搭配：`回应 解决 弥补 突破 填补 回答 补齐` 等动词后面接的宾语是否搭得上（如"回应……不足"应为"弥补……不足"；不足/空白配弥补填补、问题配解决、瓶颈配突破、关切/需求配回应满足）。
- 术语一致性已由**第 0 遍**的 `audit.py` 机械覆盖，这里只补脚本查不到的：有全称的固定术语不得随意简写；一次给出的分类表述（如"甲类/乙类/丙类"）首次出现后不得省略或改口径；无共同语素的同义词（如"波形生成模块"与"神经音频编解码器"）脚本发现不了，要靠术语表盯。

## 第 8 遍：回归——复查自己改出来的问题

**改稿必然制造新问题，这一遍不能省。** 实测一轮修改引入过四处新错：

- 全局把"失效边界"换成"失效条件"，撞出同句"……条件及其失效条件"的重复；
- 合稿时旧版句子没删干净，同一判断连着说了两遍；
- 删句时连带删掉了该段唯一的引文，评述现状的段落变成无引文；
- 换掉一个词后与前半句已有的同形词撞车（"外部参照"遇上前句的"判伪参照"）。

三条硬规则：

1. **每次全局替换后，把所有替换点连同前后各一句重读一遍。** 替换必然在替换点周围制造新的搭配、重复或同词撞车。
2. **每次删句后，检查被删句里有没有别处依赖的东西**：先行词、引文编号、术语首次定义。
3. **合稿后重跑一次 `audit.py`**，跨节复读检测能抓出合并残留。

## 术语表前置（写作前就做）

动笔前把关键术语及其固定表述整理成一张表，写作和每遍过稿都对照它。表的**结构**如下（内容按本课题填，下面是占位示例，不针对任何具体学科）：

| 概念 | 固定表述 | 禁止的变体 |
|---|---|---|
| 〔核心方法名〕 | 〔全称，如"某某分析法"〕 | 〔口语简称、近义混用词〕 |
| 〔研究对象〕 | 〔统一称谓〕 | 〔时而A时而B的变体〕 |
| 〔关键指标〕 | 〔完整指标名〕 | 〔随手缩写的版本〕 |
| 〔研究内容编号〕 | 内容一/内容二/内容三 | 第一项内容、内容① |
| 〔某分类体系〕 | 〔一次给全的分类，如甲类/乙类/丙类〕 | 首次出现后随意简写或改口径 |

每个课题的具体条目不同，表的用法通用。
