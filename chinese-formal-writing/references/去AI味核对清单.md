# 去"AI味"与去口语化 核对清单

"AI味"和"口语味"都有具体、可枚举的来源。逐条排查、逐条对治。前八项偏"AI生成痕迹"，中间六项偏"口语/汇报腔"（往往更隐蔽、最常被评审点名），15、16 是管理黑话与动宾搭配不当，17、18 是最难自查的两类——直译腔与名词压缩。可操作的过稿流程另见 `学术化过稿清单.md`。

## 1. 英文缩略语堆砌

**症状**：一句话塞多个英文缩写、协议名、标准编号或专有名词（各学科都有，如某某模型缩写、某某标准号连写）。

**对治**：概念用中文表述；确需保留的术语/标准编号首次给中文全称、之后沉到脚注或附录，正文最多留一两处。目标：正文英文术语接近零残留。

## 2. 括号补丁、插入语与免责反复

**症状**：正文大量"（……，不……，仅……）"式限定；反复出现"弹性目标、非否决项、力争、视数据条件"；插入性说明如"（如企业开办，3至5个关键节点）""（详见附录）""（作为报告附录）"频繁打断正文。同一句免责在目的、目标、内容、成果、组织、风险里各写一遍。

**对治**：边界与免责集中在"研究范围界定"处讲一次，后文不重复。括号里的限定能进主句就进主句，进不了就删或改为脚注。让正文保持连贯，不被插入语切碎。

## 3. 表格/矩阵过密

**症状**：各类对照矩阵密集排列（指标矩阵、变量—方法对照表、任务—成果对应表、文献分类表、风险—措施表等），通篇像清单而非论述。

**对治**：表格数量以申报通知与信息密度为准，正文只保留能显著提高可读性的关键表，辅助性清单、长指标表、样本说明优先下沉附录，其余改写为叙述。参见 `去列表化改写.md`。

## 4. 三字/四字并列口号式表达（明令禁止但反复出现）

**症状**（下列为反面示例，实际写作中换成本课题语境里的同类口号）："可评可管可推广""可评价、可治理与可推广""更准确、更稳妥、更规范""敢用、放心用、可持续""更快、更好"。朗朗上口但缺乏学术分量，以语义模糊换节奏感。

**对治**：任何"A、B与C"三字并列一律改为双字名词词组，或展开为完整陈述。例：
- "可评可管可推广" → "具备规范性与可操作性"
- "更准确、更稳妥、更规范" → "准确性、一致性与规范性"
- "敢用、放心用、可持续" → 展开为一句说明可信度与可持续性的陈述

## 5. 双引号与破折号泛滥

**症状**：双引号动辄上百对，且带引号的表述往往口语化重；破折号也多。

**对治**：双引号能省则省（一份稿子常能从 100+ 对压到个位数），只留术语首次定义、固定专名；破折号基本清零，改用逗号、冒号或拆句。**pandoc 陷阱**：ASCII 直引号经 smart 会全变右引号、不成对，出 docx 前用 `scripts/fix_quotes.py` 修回成对中文引号。

## 6. 长句负荷过重、定语堆叠

**症状**：三个以上定语并列修饰同一中心语，如"兼具理论解释力、实践适用性和数据可获得性的分析框架""覆盖对象识别、过程分析和结果评价的研究路径"；主谓之间插入超过二十字。阅读负担重，施动关系易不清。

**对治**：定语超过三个、或主谓间插入过长的句子一律拆分。可拆成两句，或把部分定语后置为补充。例："兼具理论解释力、实践适用性和数据可获得性的分析框架" → "构建具有理论解释力的分析框架，并说明其适用条件与数据来源"。

## 7. 段落首句口语化，非主题句

**症状**：段落首句用口语承接或设问、背景铺垫、时间状语开头——"这项研究要回答的是…""如果说 X，那么 Y…""有了 A，还需要 B…""随着……""在……背景下……"。像口播稿，不像书面论述。

**对治**：**每段首句必须是概括本段核心的主题句**，直接陈述本段要点。承接靠内容逻辑，不靠口语连接词或时间状语。首句若以"随着/在……背景下"起，考虑调整。

## 8. "研究/课题"作拟人主语

**症状**：大量以"本课题""本研究"作主语接"梳理、搭建、建立、回答"等动作，别扭且重复。

**对治**：改用无主语承接、被动式，或"课题组"等恰当主语。同一段避免连续多句都以"本课题"开头。

## 9. 口语化衔接词与过渡语（最突出、几乎每段都有）

**症状**："需要说明的是""需要特别指出的是""值得强调的是""总体而言""从政策导向看""在此基础上""与此同时""换句话说""也就是说"。口头汇报自然，学术书面语里显得松散随意，削弱论证严谨感。

**对治**：检索到即审视能否删除或替换。多数可直接删去，让句子自然衔接；确需过渡的用内容逻辑承接，不用套话式插入语。完整自查词表见 `学术化过稿清单.md`。

## 10. 工作汇报腔

**症状**："陆续上线""已初步显现""陆续展开""稳步推进""扎实落地""可操作、可落地""稳中求进"。项目进展报告里恰当，学术申报书里应转为中性、客观的学术判断。

**对治**：把"阶段性总结/工作汇报"色彩的动词短语换成事实陈述。例："相关系统陆续上线" → "已有若干地区部署相关系统"；"成效已初步显现" → 用具体事实或"在 X 方面呈现 Y"。

## 11. "稳妥/妥善"等模糊副词过度且不一致

**症状**："稳妥应用""妥善处理""稳步推进"反复出现，语义含混；同一概念时而"稳妥"、时而"稳健"、时而"规范"，前后不一。

**对治**：模糊副词一律审视有无精确指向，能删则删、能具体化则具体化；同一概念全篇统一用词（见术语一致性）。

## 12. 形容词偏好强、程度副词滥用

**症状**："显著提升""实质性推进""高度契合""较大程度""核心突破"。带主观评价色彩，学术写作应以事实和逻辑说话。

**对治**：每段检查程度副词（显著/较大/高度/实质性/核心）数量，无客观依据支撑的删除或改中性。"核心突破""实质性推进"等自评式表述改客观描述："本课题提出……""该方法的特征在于……""相比既有研究，本课题的差异在于……"。

## 13. 过于绝对/夸大

**症状**：两类。一类是自评式夸大——"颠覆性""国际领先""首创""实质性推进""核心突破"。另一类更隐蔽，是**全称与绝对化的判断词**：不再、任意、都会、始终、只能、无法、无从、必然、完全、均不能。

**判定动作**：问这个论断**有没有合理的例外**，以及手上的证据只能支持"趋势／可能性／相对比较"还是真能支持"全称"。有例外或证据只到趋势，就必须降级。

**对治**：按证据强度改用限定词——大致、较、可能、通常、尚难、易、未必、相对；把全称结论改成条件化结论。差异用"相比既有研究，本课题的差异在于……"客观陈述。

> 未见编解码器**都会**使检测性能下降 → **均可能导致**检测性能下降

**例外**：数学定义、明确的制度规定、实验设置里的硬约束可以用绝对词，但要有可核验依据。

## 14. 汇报腔句型

**症状**："一是……二是……三是……"连续列举开头；"既要……又要……""不仅……而且……"对举；"正由……向……转变"进行时态。

**对治**：学术写作多用"体现为""包括""体现在"等静态判断句式。"一是二是三是"改为有主题句的分段论述（见 `去列表化改写.md`）。

**同类还有过度工整的排比**："前者……后者……两者都……""既……也……"、连续多个"只"、"先从—继而—随后—近期"式的四段推进。**判定**：句式高度对称，但逻辑层次其实并不对等，或者连续排比本身就产生了模板感。**对治**：拆句，按事实的重要性重新组织，减少重复的连接词；两项确实严格对照时才保留对称结构。

## 15. 管理黑话与互联网流行词

**症状**："赋能、抓手、闭环、打法、破圈、心智、生态位、底座、链路、组合拳、护城河、一体化推进"等管理话术/互联网黑话。出现在**标题**里尤其扎眼、显得不专业。

**对治**：一律换成学科规范术语。"赋能"→"支撑/提升/服务于"；"抓手"→"着力点/途径"；"闭环"→"完整流程/反馈机制"；"底座"→"基础/支撑"。研究内容、章节、创新点等标题更要清理干净——标题用规范学术名词短语、不用口号式动宾并列（拟题规范见所属文体 skill 的结构规范，如申报书见 `grant-proposal-writing` 的 `结构与篇幅.md`）。

## 16. 动宾搭配不当、生硬搭配

**症状**：动词与宾语不合习惯，读着别扭。典型如"回应现有研究的不足"（回应的对象应是问题/关切/需求，不是"不足"）、"解决……短板""回答……痛点""突破……不足""填补……问题"。多见于 AI 生成或快写的学术中文，语义看似通、搭配实则错。

**对治**：按对象选对动词——不足/空白用"弥补、填补"；问题/难题用"解决、攻克";瓶颈用"突破";关切/需求用"回应、满足";短板用"补齐"。例："回应现有研究的不足" → "弥补现有研究在……方面的不足"（研究意义语境也可改为"深化……领域的研究"）。改稿时留意"回应/解决/弥补/突破/填补/回答"这几个动词后面接的宾语是否搭得上。

## 17. 英文直译词（长得像中文，其实读不通）

**症状**：与第 1 条的"英文缩略语堆砌"不是一回事。这一类**全是汉字**，扫读时不觉得突兀，但读者复述不出意思，因为它是英文术语的逐字直译。实测抓到的：

| 文中写法 | 原文 | 问题 |
|---|---|---|
| 增量信息 | incremental validity | 读不出"控制住已有变量后还剩多少解释力" |
| 捷径 | shortcut learning | "排除捷径"搭配不成立 |
| 未见编解码器 | unseen codec | "未见"在中文里不能作定语直接修饰名词 |
| 生成主干 | backbone | "主干"在中文里不指网络主体结构 |
| 效应保留程度 | effect retention | 读不出"换到未知条件后效应还剩多少" |
| 整体表示驱动 | representation-driven | "表示驱动"不成词 |
| 正常变异 | normal variation | 生物统计学词，此处指"本来就有的波动范围" |

**判定动作**：把这个词念给**同领域但不同方向**的人听，看他能不能复述出意思。念不出来就得展开。

**对治**：三选一——① 展开成一句话（"在已有维度之外是否还有额外解释力"）；② 换用中文里已成词的对应说法（"未见 X" → "训练中未出现的 X"）；③ 确需保留的技术术语，首次出现时补一句释义（"视为存在捷径，即模型借助与真假偶然相关的信息作出判断"）。

## 18. 名词压缩过度

**症状**：中文学术写作特有的失败模式——四到六字的名词串把语法关系吃掉，读者要反推才知道谁修饰谁。"开放环境边界""开放环境稳定性""风险解释价值""跨层证据额外信息""真假监督"。

与第 6 条（长句定语堆叠）相反：那是修饰成分太多太长，这是该有的虚词全被省了，句子反而太短。

**判定动作**：在名词串中间试着**插回"的""在……中的"**——插不回去，就是压过头了。"开放环境边界" → "在开放环境中的适用范围" ✓；"真假监督" → "真假标签监督" ✓。

**对治**：把省掉的介词、结构助词补回来。宁可多三个字，不要让读者反推。

## 19. 机械段尾总结与结构提示

**症状**：段落末尾挂一句不增加任何信息的总结或章节导航。三种典型形态：

- **价值总结**："因此，以……为出发点，仍有值得开展的工作。"
- **产出复读**："由此形成……"——而上一句刚说完同一件事。
- **结构对号**："前一方向对应……，后一方向对应……，分别对应下文的两项研究内容。"

这类句子在多章节文稿里成批出现，是 AI 生成最稳定的节奏之一：每段都要有个"收"，于是收出一堆空话。人写作时段落是可以不收的。

**判定动作**：把这句**整句删掉**，看上下文逻辑是否受损。不受损就是废话。

**对治**：优先直接删。确需保留时，换成**具体判断、具体研究问题或具体产出**——"这表明，从真实语音形成规律中寻找判伪依据可能更具稳定性"就比"仍有值得开展的工作"有信息。

**例外**：跨节转折确实引入了新逻辑时可以保留，但必须提供新信息，不能只是回指。

## 20. 数量词后置

**症状**："评测子集1个""代码工具1套""方法三项""发表论文3篇，其中B类2篇"。数量放在名词后面，是表格填报的语序，出现在正文里显得像机器拼接。

**对治**：正文一律前置——"1个评测子集""1套代码工具""三项方法"。

**例外**：指标表格、成果清单表里的后置数量是正常的，不必改。


## 21. 行政公文词与空泛动词

**症状**：两类词让学术文稿变成机关文件。

**行政词**：予以标定、下设三项方案、实施……方法、建成……子集、加以控制、开展……工作。这些词在学术语境里不增加任何信息，只增加距离感。

> 尚需由风险等级**予以标定** → 还需**结合**独立标注的风险等级**进行分析**
> **下设**三项方案 → **包括**三方面研究
> **实施**风险等级构建**方法** → **完成**正式标注和风险等级**估计**

**空泛动词**：处理、给出途径、形成定义、区分、明确、建成并实施。判定标准很简单——**这个动词能不能说清你实际要动的是数据、模型、评测还是产出**？说不清就换。

> **区分**真假检测、目标身份匹配与场景后果 → **分别评价**真假、目标身份匹配与场景后果
> **给出**可证伪的验证途径 → **建立**具有明确否证条件的验证方案
> **明确**捷径信息残留与适用范围 → **识别**捷径信息的残留影响，并**界定**证据的适用范围

**可换用的具体动词**：整理、核查、构建、估计、训练、检验、评测、比较、界定、集成、标注、分层、留出。

**例外**：总体概述可以用"开展研究"这类笼统说法；正式制度文件里的固定表达（如"予以批准"）不必强行口语化。分项方案必须具体。

**顺带看量词**：抽象成果的量词容易搭错——"一**项**风险等级"不如"一**套**风险等级及其标注依据"。成果是体系时用"套"，是单件产出时用"个"。

## 快速量化自检

**首选跑脚本**，它把下列检索连同术语漂移、跨节复读、引文顺序、孤图一并报出：

```bash
python3 scripts/audit.py 正文目录/ --skip 00-
```

手工检索时用下面这组（脚本不可用时的兜底）：

```bash
# 双引号对数（中文引号，除以2约为对数）与破折号
grep -o '“' file.md | wc -l ; grep -o '——' file.md | wc -l
# 口语衔接词 / 汇报腔 / 模糊副词 / 管理黑话
grep -oE '需要说明|需要指出|需要特别指出|值得强调|总体而言|在此基础上|与此同时|也就是说|换句话说|稳妥|妥善|稳步|扎实|陆续|初步显现|实质性|核心突破|显著|赋能|抓手|闭环|打法|破圈|底座|链路' file.md | sort | uniq -c
# 加粗编号小标题（AI味列表残留）
grep -cE '^\*\*[（(]?[一二三四五六0-9]' file.md
# 英文残留
grep -oE '[A-Za-z]{2,}' file.md | sort | uniq -c | sort -rn | head
```

某次重构的量级参考（仅示意改善幅度，**不作为通用验收指标**）：双引号 116 对 → 1 对，破折号 17 → 0，加粗编号小标题 → 0，英文术语正文零残留。引用政策原文、访谈材料、术语定义较多的课题，该保留的引号与术语按引用必要性保留，不必追求个位数。

**注意计数指标的盲区**：这些数字全部下降，不等于稿子干净。第 17、18 条（直译词、名词压缩）和 `可读性核对清单.md` 的七条，都不会体现在任何计数里——实测中它们恰恰是评审最容易卡住的地方。
