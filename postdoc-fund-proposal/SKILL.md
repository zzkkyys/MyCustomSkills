# 中国博士后科学基金面上资助申请书写作

## 用途

帮助撰写、重构、润色《中国博士后科学基金面上资助申请书》的**『二、项目信息』正文**（个人信息、承诺等表单栏目不在本 skill 范围）。

这类申请书与一般课题申报书最大的不同，是**三条不可协商的硬约束**——本 skill 的全部要点都围绕它们展开：

1. **栏目固定、字数上限死板**。六个正文栏目及字数上限是系统级强制，不能增删栏目、不能超字：
   | 栏目 | 字数上限 | 要点 |
   |---|---|---|
   | 1. 选题依据 | **1000 字** | 国内外研究现状及选题价值 |
   | 2. 研究内容 | **2000 字** | 研究对象、拟解决的关键科学问题、研究目标 |
   | 3. 研究方案 | **2000 字** | 技术路线、方法、可行性 |
   | 4. 特色与创新之处 | **1000 字** | 相对已有工作到底新在哪 |
   | 5. 研究计划及预期成果 | **500 字** | 阶段计划 + 具体成果 |
   | 6. 研究基础 | **1000 字** | 积累/条件/在研项目（**唯一可含身份信息的栏目**）|

2. **匿名评审红线（触线可致该项目计 0 分）**。填报须知明确：『二、项目信息』中（**"研究基础"除外**）不得出现申请人姓名、设站单位名称、合作导师姓名等泄露身份的信息，否则评审专家可视为故意泄露、计 0 分。原文用词是"可视为……计 0 分"，但后果是该项目评审直接归零，**实务上一律按硬红线处理**。这是全篇最大的风险点，见 `references/匿名评审红线.md`。

3. **极致精炼，而非控制膨胀**。一般申报书的病是"越写越长"；这里恰相反——**信息密度要在极小预算里最大化**，每句都要挣其字数。500/1000 字的栏目容不下任何客套、过渡水词、重复铺垫。见 `references/字数与精炼.md`。

## 与 chinese-formal-writing 的分工

本 skill **只管这类申请书特有的部分**：固定栏目、字数、匿名、分节写作要点。**通用写作工序不在这里重复**，直接复用配套 skill `chinese-formal-writing`（下列路径均指该 skill 目录，不在本 skill）：

- **去AI味与口语味**（英文缩略语、双引号/破折号泛滥、口语衔接词、汇报腔、程度副词、口号式并列）→ `chinese-formal-writing/references/去AI味核对清单.md`、`chinese-formal-writing/references/学术化过稿清单.md`。
- **去列表化**（把"目标:/(1)(2)"条目、加粗编号小标题改写为主题句段落）→ `chinese-formal-writing/references/去列表化改写.md`。
- **标题专业化、术语全文统一、逐段/分批审阅** → 其 SKILL.md 与 `chinese-formal-writing/references/审阅prompt.md`。
- **docx 出稿与公文格式**（若需离线送审或给导师传阅）→ `chinese-formal-writing/references/格式与docx.md` 与 `chinese-formal-writing/scripts/`。

建议两个 skill 一起安装；未装 `chinese-formal-writing` 时，本文各栏的要点提示仍可用，只是缺少那几份详细清单与出稿脚本。

**复用时的一处必要改造**：`chinese-formal-writing` 的审阅/改写建议会把生硬主语换成"课题组""本团队"等——这在栏目 1~5 恰恰是**匿名红线要删的词**。对本类申请书栏目 1~5 套用其审阅 prompt 时，务必先加一条约束："保持匿名，不得出现姓名/单位/导师/课题组/本团队等身份指代"，否则会引入泄露风险。

**注意本类申请书通常由申请人在"中国博士后科学基金管理信息系统"在线填报、系统自动生成，最终提交是把每栏文本粘进固定文本框。** 因此本 skill 的交付物是**每栏合规文本（markdown 草稿即可）**，docx 仅用于离线打磨/送审，非必需。

## 何时用 / 何时不用

**用**：写或改博后面上申请书的六个正文栏目；用户抱怨"某栏超字了""这段像列表""匿名有没有踩雷""创新点写虚了"。

**不用**：一般纵向/横向课题申报书、自然科学基金、社科基金等 → 用 `grant-proposal-writing`；个人信息表、保密审查证明、承诺等表单附件 → 按模板逐栏填，不需要本 skill。

## 动手前必须问清楚

**不要一上来就写。** 先对齐下面几件事，写进计划文件：

0. **先核对当届模板与系统。** 本 skill 的栏目/字数依据的是**第 80 批模板**，逐批可能微调（栏目括注、字数、能否插图、字数计数口径、申报截止时间等）。开写前让用户对照**当届申报通知与在线系统实际界面**确认一遍；有出入以当届为准，并更新 `references/模板与栏目.md`。
1. **主线是什么？** 这个课题要解决的核心科学问题、核心方法是哪几块。这是六栏重心排布的依据——研究内容围绕 2~4 个关键科学问题展开，研究方案、创新点、预期成果都要与之一一对应。**必须先和用户确认，不要自己猜。**
2. **有没有真实数字与既定信息？** 进站周期（面上通常按博后在站期安排阶段计划）、拟产出成果的口径（论文/专利数量是否要写死）、依托的在研项目——未定就不要写死。
3. **身份信息边界**：确认设站单位名、合作导师名、申请人本人已发表工作的提法，哪些必须回避（栏目 1~5）、哪些放到研究基础（栏目 6）再具名。见匿名红线。

标题、学科归属（一级/二级学科、交叉学科）、项目来源（自选/合作导师项目/自主获得的国家或省部级课题/其他）等也在计划阶段一并确认。栏目原文与字数见 `references/模板与栏目.md`，**逐字持久化，不要自行改栏目名或增删**。

## 总体工作流

**先完成上面三问，写"说明与分解计划"，再动手。**

1. **建子文件夹 + 写计划文件**（如 `00-说明与分解计划.md`）：主线定位、六栏字数预算表、每栏拟写要点、匿名边界清单、待确认数字。就地向用户确认关键决策后再逐栏实施。
2. **逐栏实施**，一栏一个文件（`01-选题依据.md` … `06-研究基础.md`）。每栏写完**立即数字数**（见下），超了当场砍，不要攒到最后。
3. **匿名自检**：栏目 1~5 逐段扫身份信息，见 `references/匿名评审红线.md` 的检查清单。
4. **过稿**：先按 `references/分节写作要点.md` 核对每栏该有的要素齐不齐；再借 `chinese-formal-writing` 的学术化过稿清单分遍查（口语词/形容词/术语一致/主题句/去列表化）。
5. **（可选）出稿送审**：需要给导师传阅或离线批注时，用 `chinese-formal-writing` 的 pandoc + `format_docx.py` 合成 docx。在线提交则直接粘贴各栏文本。

每写完一两栏就请用户复核，不要一口气写到底。

## 数字数（每栏必做）

字数是硬门槛，**每栏写完、每轮改完都要数一次**，留 3%~5% 安全余量（例如 1000 字栏目控制在 950~980）。数的是正文本身，不含 markdown 标题/注释。快速统计：

```bash
# 去掉 markdown 标题行后统计字符数（含标点，近似系统口径）
grep -v '^#' 01-选题依据.md | tr -d '[:space:]' | wc -m
```

系统一般按字符计数（含标点），无空格。若临界，以系统实际计数为准；宁可略欠，不可超限。精炼手法见 `references/字数与精炼.md`。

## 分节写作要点（概览）

详见 `references/分节写作要点.md`，此处只记每栏的命门：

- **选题依据（1000）**：现状综述要"收敛到缺口"——国内外进展一两段带过，落点是**尚未解决的问题**与本课题的科学/应用价值，不要写成文献流水账。
- **研究内容（2000，核心栏）**：显式交代**研究对象、关键科学问题、研究目标**三要素；围绕 2~4 个关键科学问题组织，用"第一/第二"序数便于评审数点（这类序数是有意保留的结构标记，过稿去列表化时不要删）。
- **研究方案（2000）**：与研究内容逐项对应的技术路线、方法与可行性；要具体可操作，别停在原则性表述。技术路线图若系统允许可放，能显著提升可读性。
- **特色与创新之处（1000）**：**评审打分重仓栏**。逐条讲清相对已有工作到底新在哪，区分"特色"（做法上的特点）与"创新"（真正的新知识/新方法）；用序数枚举，不空喊、不过度宣称。
- **研究计划及预期成果（500，最小预算）**：按在站阶段/年度排时间轴 + 列具体可核查成果；每字都金贵，用短句。
- **研究基础（1000，唯一可具名栏）**：三要素——相关积累与已有成绩、已具备/尚缺的条件及解决途径、在研的相关项目；这里才具名自引与依托单位/合作导师。

## 关键提醒

- **匿名是第一红线**，一处身份泄露就可能让该项目评审计 0 分，代价远大于文字瑕疵。栏目 1~5 里凡是"本人""我们团队在 X 大学""导师 XX 的前期工作"都要改写或下沉到研究基础。
- **字数是第二硬门槛**，写作时就按预算分配，别指望最后再压缩——大砍会伤结构。
- **有意保留的序数不要删**：关键科学问题、创新点、研究阶段里的"第一/第二…"是给评审数点和看时间轴用的，去列表化时保留。
- **不写死不确定的数字**（成果数量、周期），未经用户确认不写。
- **术语全文统一、标题用规范学术名词短语**，规则见 `chinese-formal-writing`，不用口号式动词并列或管理黑话。
