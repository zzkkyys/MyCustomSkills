# 卡字数：分配策略与精炼手法

字数上限是系统硬门槛，超一字都提交不了。与一般申报书"防膨胀"不同，这里的功夫是**在极小预算里把信息密度做到最大**。核心原则：**写作时就按预算分配，不要指望最后再压缩**——临交付大砍会伤结构、丢逻辑。

## 计数口径与安全余量

- 系统一般**按字符计数，含标点、不含空格**；中英文各按其字符算。以系统实际计数为准。
- 每栏**留 3%~5% 余量**：1000 字栏目控制在 950~980，500 字栏目控制在 470~485。临界宁可略欠，不可超。
- 每栏写完、每轮改完都数一次：

```bash
# 去掉 markdown 标题行，去所有空白，统计字符数（近似系统口径）
# 注意：wc -m 必须在 UTF-8 locale 下才按"字符"计；否则退化为按字节计（中文一字算 3），结果虚高。
LC_ALL=C.UTF-8 grep -v '^#' 01-选题依据.md | LC_ALL=C.UTF-8 tr -d '[:space:]' | LC_ALL=C.UTF-8 wc -m
```

一次数全部六栏：

```bash
export LC_ALL=C.UTF-8   # 若报错换 zh_CN.UTF-8 或 en_US.UTF-8
for f in 0[1-6]-*.md; do printf '%s\t' "$f"; grep -v '^#' "$f" | tr -d '[:space:]' | wc -m; done
```

若 locale 不便设置，用 Python 更稳（`len()` 直接按字符算）：

```bash
python3 -c "import sys,re; s=open('01-选题依据.md',encoding='utf-8').read(); s=re.sub(r'(?m)^#.*$','',s); print(len(re.sub(r'\s','',s)))"
```

## 预算分配（写前先在计划里排）

- 大预算栏（研究内容、研究方案各 2000）承载主体论证；小预算栏（研究计划及预期成果 500）只放骨架。
- 每栏内部再切块：如研究内容 2000 字分给"对象+目标"约 300、每个关键科学问题约 400~500。写之前就把块预算写进计划文件，写的时候对着预算走。
- 各栏内容**不重复**：选题依据讲"为什么"，研究内容讲"做什么"，研究方案讲"怎么做"，创新点讲"新在哪"，别让同一句话在多栏出现——重复是最浪费预算的。

## 精炼手法（在保结构、保信息的前提下压字）

1. **删水词与客套**：去掉"众所周知""随着……的发展""为了更好地""在此基础上""值得一提的是"这类零信息开头；口语衔接与汇报腔的清单见 `chinese-formal-writing/references/去AI味核对清单.md`。
2. **删程度副词与自我评价**："显著地""极大地""非常重要""具有重大意义"——改客观陈述或直接删。
3. **动词化名词短语**："进行了……的研究"→"研究了……"；"实现对……的分析"→"分析……"。
4. **合并重复限定**：同一对象的多个定语能合则合，超过三个定语的长句拆短。
5. **一句一义**：把"因为……所以……并且……从而……"的长链拆成短句，反而更省字、更清楚。
6. **用序数替代过渡段**：关键科学问题、创新点用"第一/第二"直接领起，省掉"接下来讨论""另一方面"这类过渡（序数本身是评审要数的结构标记，保留）。
7. **删可推断的话**：结论能从论证自然得出的，不再单开一句复述。
8. **图代文**（研究方案）：若系统支持插图，技术路线图可替下大段文字描述——注意图中不得含身份水印（见 `匿名评审红线.md`）。

## 与去列表化的配合

去列表化（把"(1)(2)"条目改成主题句段落，见 `chinese-formal-writing/references/去列表化改写.md`）会略增字数。在字数极紧的栏目里，二者要平衡：**保留有意的序数、化掉机械的裸条目，但不为了"成段"而注水**。段落以主题句领起即可，过渡从简。

## 不要为了凑字数注水

预算没用满是正常的，**宁可略欠也不加套话**。评审看的是信息密度，凑字数的空话反而拉低观感、挤占本该写实质的空间。
