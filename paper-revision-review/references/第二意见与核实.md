# 第二意见与核实

让另一个模型独立复审同一章，再做三方对照。实践中约**三分之一**的问题是单方发现的，值得做。

---

## 一条铁律

> **别人报的问题，先核实再采信。**

第二意见会给出**看起来很具体、实际不成立**的断言：引用不存在的 URL、报错的行号、图里根本没有的文字、编造的统计数字。它也会**推翻你自己的结论**——那种时候要立刻验证并如实更正。

分三种处理：

| 情形 | 处理 |
|---|---|
| **本地可核实**（行号、拼写、符号、bib 条目、数字重算、页数、图片内容） | **必须逐条核实**。属实才写进条目；不属实要在条目里写明「此条不成立」及正确事实 |
| **本地不可核实**（外部论文的机制描述、会议的具体格式规则） | 写进条目但标 `⚠️`，说明依据来自第二意见、无法离线验证，请作者确认 |
| **推翻了你自己的判断** | 立刻验证。若对方正确，把条目**重写**并注明「本条已被推翻，方向与我最初的建议相反」——不要悄悄改掉 |

核实成本通常很低（一条 `grep`、一次重算、打开一张图），而把错的当对的写进条目，会直接损害整份审阅材料的可信度。

**同时也别过度让步。** 第二意见对同一处可能只说对了一半：例如它指出「图注未披露截断」措辞上对，但图本身用醒目标注披露了——这时要为作者说明这一点，只保留真正成立的部分（截断柱与未截断柱同框导致视觉失真）。

## 三方对照

合并时给每条打来源标记：

- **`both`（双方共识）** —— 两个独立评审都指出，最可靠，**优先改**
- **`codex`** —— 第二意见独有。核实通过才写进去
- **`mine`** —— 本轮独有。第二意见没提，不等于不成立

在页面头部说明三者的数量，让作者知道哪些是「双重确认」的。

## Prompt 模板

按章节替换【】部分。**不要把自己的发现写进 prompt**——否则对方只会顺着你的判断附和，第二意见就失去意义了。

```
请对一篇准备投稿【会议/期刊】的论文的【第 N 章 章节名】做一次严格的同行评审式审阅。

文件：【绝对路径】

审阅范围：第 X–Y 行【列出该章包含的小节、公式、图表环境】
【注意：第 A–B 行是被注释掉的旧草稿。可以参考作者原本的思路，但不要把注释里的
内容当作正文问题来报告。】

论文背景：
【三到五句：做什么、核心方法、核心声称。让对方有足够上下文判断 overclaim。】

【关键】本章必须与论文其余部分自洽。请务必读取以下内容做交叉核对，
不要只在本章内部看：
- 第 X–Y 行：【相关章节及要核对什么】
- 同目录 【appendix.tex / ref.bib】：【要核对什么】

请重点检查以下 N 类问题，逐条给出 文件名:行号 + 问题 + 具体修改建议：
1. 【按 references/分章审阅清单.md 里对应章节的条目列出，标注哪几类是「重点」】
...
以及常规检查：语法、冠词单复数、搭配；LaTeX 层面会影响 PDF 输出的问题
（句号后缺空格、\cite 前缺 ~、多余空格、引用命令写法不统一等）。

输出格式（严格遵守）：

【必须修改】
- 文件名:行号 — 原文引用 — 问题是什么 — 审稿人会怎么看 — 建议改成（具体文本）

【建议修改】
（同上格式）

【可选润色】
（同上格式）

【<章节特定的专项输出>】
【例：数字核对表 / 理论严谨性总评 / 方法可复现性总评 / 全文完整性检查表】

硬性要求：
- 每一条都必须带具体行号和原文引用，没有行号的条目不要写
- 修改建议必须给出可直接替换的文本，不要只说"建议改进措辞"
- 第【N、M】类问题请逐个/逐行核对后再下结论，不要抽样
- 不要修改任何文件，只输出审阅意见
- 请先完整读完上述所有区间再动笔
- 如果某项检查没有发现问题，明确写"未发现问题"，不要略过不提

补充：作者【时间约束，如"今天必须投稿"】，不会补充任何新实验。因此所有建议
都必须是"只改文字、只补录已有信息、或限定声称范围"就能落地的。凡是需要新实验的
问题，请明确标注为"无法今天解决"，并给出对应的表述限定方案。
```

## 几条让 prompt 更有效的做法

**要求「逐个核对，不要抽样」。** 符号一致性、命名一致性、引用准确性、数字自洽这几类，抽查必漏。明确写出哪几类不许抽样。

**要求它真的动手算。** 涉及数字时加一个强制输出段：

```
【数字核对表】
逐项列出你重算过的每一个数值，格式为
「正文声称 X（:行号）｜ 从表格重算得 Y ｜ 一致/不一致」
```

不加这一段，它很可能只说「未发现问题」而没真算。

**要求它明确说「未发现问题」。** 否则无法区分「查过没问题」和「跳过没查」。

**给出时间与资源约束。** 否则会收到一堆「建议补充实验」——赶投稿时用不上。

**专项输出段按章定制**：
- 实验章 → 数字核对表
- 理论章 → 理论严谨性总评（按危险程度排序最可能被攻击的点）
- 方法章 → 可复现性总评（第三方能否复现，缺什么）
- 结论/收尾 → 全文完整性检查表（Limitations/Ethics/可复现性/未引用标签/未引用文献…）

## 如果第二意见跑不出来

不要干等。曾出现连续三轮只返回进度描述、没有任何行号和结论的情况——那说明链路有问题，不值得继续等。

做法：**先自己完成一轮「对立审稿人」视角的复审**（专门找第一轮漏掉或判断太轻的地方，尤其是 overclaim、理论与实验的匹配度），产出可用的东西；等对方真的返回结果再合并。

如实告诉作者当前状态：哪些是已完成的、哪些还在等、以及你打算等多久。
