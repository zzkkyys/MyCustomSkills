# 页面容量与写作约束

以下字数按 16:9 中文幻灯片估算，应结合实际渲染结果调整。

## 多栏容量

| 布局 | 标题建议 | 正文每行 | 建议列表项 |
|---|---:|---:|---:|
| `columns-2` | 8–10 字 | 18–20 字 | 4–6 项 |
| `columns-3` | 6–8 字 | 12–14 字 | 3–4 项 |
| `columns-4` | 4–6 字 | 8–10 字 | 2–3 项 |
| `columns-2x2` | 8–10 字 | 16–18 字 | 3–4 项 |
| `columns-2-colors` | 8–10 字 | 18–20 字 | 4–5 项 |
| `columns-3-colors` | 6–8 字 | 12–14 字 | 3–4 项 |

## 图文与时间轴

| 布局 | 标题建议 | 正文每行 | 说明 |
|---|---:|---:|---|
| `img-left/right` 文字区 | 10–12 字 | 20–22 字 | 图片约占 45% |
| `timeline` | 10–12 字 | 30–35 字 | 接近全宽 |
| `timeline-horizontal` | 4–6 字 | 8–10 字 | 建议三至四列 |

## 特殊组件

| 组件 | 建议 |
|---|---|
| `big-number .label` | 4–6 字 |
| `big-number .unit` | 1–2 字 |
| `tag` | 2–5 字 |
| 提示框 | 每行约 35–40 字，控制在三行以内 |
| `title h1` | 建议 10–24 字；网格首页允许自然换行，过长时拆成主副标题 |
| 内容页 `h1` | 默认最多两行；预计三行时使用 `long-title`，超过约 54 字优先缩短 |
| `section-divider h1` | 6–10 字 |
| `quote` | 30–50 字，并标明来源 |
| `toc` | 每项 8–12 字，建议三至六项 |
| `thanks` | 一个主标题和一行结束语，不堆叠联系方式 |
| `image-caption` | 一至两行，避免遮挡图片主体 |
| `footnotes` | 最多约三行，不承载正文论证 |
| 常规表格 | 建议不超过六列、六行；数值列右对齐 |
| `small-text` 表格 | 建议不超过八列、六行；仍拥挤时拆页 |

## 超限处理顺序

1. 删除与本页结论无关的内容。
2. 将复合结论拆为两页。
3. 将四栏改为两栏或 2×2。
4. 用关键词替代完整句，但保留逻辑关系。
5. 只在参考文献、附录等页面使用 `small-text` 或 `tinytext`。

## 内容纪律

- 每页围绕一个可复述结论组织信息。
- 让图表标题说明结论，而非只写“实验结果”。
- 保留数字的口径、单位、时间范围与来源。
- 不使用未经核实的名人名言、统计数据或“行业平均值”。
- 同一层级的并列项保持语法结构一致。
